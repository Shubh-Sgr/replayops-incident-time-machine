## Direction contract

THESIS: The connector surface removes the manual evidence-entry bottleneck. It lets an operator create one signed receiver, understand exactly what will be retained, verify the entire path with a labeled test, and inspect delivery health without database access.

OWN-WORLD: Extend the Industrial Chronograph Bench. Connector state uses the established blue-charcoal instrument neutrals, telemetry cyan, incident orange, calibrated rules, mono credentials, and explicit status marks. No new visual identity, OAuth-marketplace theater, or decorative integration-logo grid.

STORY: An operator sees the source → buffer → proof-loop mechanism, chooses GitHub, OpenTelemetry, or generic webhook ingestion, creates a receiver, copies provider-specific setup, runs a safe synthetic test, and confirms that a delivery created an incident. Ordinary changes stay buffered; incident-shaped signals cross the threshold.

FIRST VIEWPORT: Lead with the automatic evidence mechanism, not a settings heading. The three-stage flow and source creation control explain why this product is useful before credentials appear. Existing receivers and their latest health remain visible beside source creation on desktop and directly below it on mobile.

FORM: A whole Operate surface inside the established product shell. Signature interaction: creating a receiver reveals an inline, provider-specific wiring bench with copyable endpoint/secret, a labeled end-to-end test, and an idempotent delivery ledger.

FINISH: Desktop and mobile behavior, loading/error/empty/connected states, token masking, destructive confirmation, keyboard focus, and reduced motion are required. The surface is incomplete if a user cannot verify the automatic incident path without reading repository documentation.
