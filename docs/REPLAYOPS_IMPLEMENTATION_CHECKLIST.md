## Remaining external and bounded limitations

- Real GitHub/Grafana/OTLP delivery health needs at least one configured external source; self-tests are intentionally insufficient.
- External Gemini grounding needs `GOOGLE_AI_API_KEY`; deterministic local analysis remains available without it.
- Independent production approval needs a second real member. The demo does not weaken the policy to self-approve.
- HTTP replay intentionally runs only against a loopback service in an isolated local/CI job. Public ReplayOps hosting must not receive production write credentials.
- Evidence endpoint pagination is bounded at 100 items, but PostgreSQL currently hydrates an incident before slicing the response; true database cursor fetching remains the large-scale optimization.
- Evidence-bundle expiry is declared and audited at creation; enforcement after someone exports the bundle belongs to the destination storage/access system.
